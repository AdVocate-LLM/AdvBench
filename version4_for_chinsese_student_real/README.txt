================================================================================
问卷调查文件夹结构说明
================================================================================

总共包含 20 个精选query的调查问卷
比较的方法: GIR-R, Ad-Chat

选择标准:
1. 回答长度筛选: 100-2000字符
2. LLM可行性评分,从以下维度评估(针对中国本科生):
   - 问题真实性: 是否是真实用户问题,而非任务型测试问题 [关键筛选,<5分将被过滤]
   - 常识认知适配性: 是否在中国本科生常识范围内,不涉及过多国外文化内容
   - 评判可行性: 中国本科生能否客观评价回答质量
   - 问题代表性: 是否是中国本科生大概率会问的问题
   - 回答差异性: 两个回答是否有明显差异
3. 过滤问题真实性<5分的问题(过滤任务型/人造问题)
4. 选择综合得分最高的前20个query

每个Query文件夹包含以下文件:
1. query.txt - 问题的原文、中文翻译、数据集来源和类别信息
2. response_[哈希值].txt - 2个方法的回答(带哈希编号)
3. evaluation_scores.csv - 该query在6个定性维度的得分
4. qualitative_evaluation.txt - 定性评估问卷(人工打分用)
5. questionnaire_format.csv - 问卷星格式的CSV文件

根目录文件说明:
- questions_source_summary.csv: 所有问题的来源汇总(数据集、类别、得分)
- feasibility_scores.json: 每个问题的详细可行性评分
- hash_mapping.json: 回答哈希值与方法的对应关系
- README.txt: 本说明文件

定性评估的6个维度:
1. 准确性 (Accuracy): 评估回答的相关性和准确性,是否直接回答了用户的问题
2. 自然度 (Naturalness): 衡量广告插入是否破坏了对话的流畅性和自然性
3. 个性化 (Personality): 评估聊天机器人在‘帮助用户’和‘推销产品’两个维度的表现
4. 信任度 (Trust): 衡量用户对整个回答的可信度和公正性的感知
5. 广告注意度 (Ad Notice): 模拟用户是否会注意到回答中的产品或品牌,以及对其的态度
6. 广告点击意愿 (Ad Click): 模拟用户是否会点击回答中的产品或品牌链接

注意事项:
- 所有问题均已针对**中国本科生**的认知水平和文化背景进行筛选
- 问题来源于不同数据集和类别,详见questions_source_summary.csv
- 每个回答都有唯一的哈希编号,用于匿名化和溯源
- hash_mapping.json 文件记录了哈希值与方法(GIR-R/Ad-Chat)的对应关系
- feasibility_scores.json 文件记录了每个query的可行性评分详情
- 评分采用1-4分制,分数越高表示该维度表现越好
- 6个维度基于LAAJ Evaluator的评分原则定义
- 数据来源: 自动从benchmark输出目录加载,经过去重、长度筛选和LLM可行性评分
